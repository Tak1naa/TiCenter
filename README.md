# AI 题库工作台

围绕题目文件阅读、选择上下文、检索和侧边 AI 对话的 Web 项目，包含学生端与独立管理端。

技术栈：React / TypeScript、Java / Spring Boot、MySQL、Redis、Qdrant，以及 Python AI 服务。

## 当前状态

这是暂停开发时的进度快照，不代表完成验收或可直接用于生产。

- 文件优先工作区、多文件标签、页面和选区上下文、引用回跳与整理草稿已写入代码。
- LlamaIndex / Qdrant 与 Xiaomi OCR 接入正在迁移，跨服务配置和真实依赖测试尚未完成。
- 双小模型训练工具链、正式数据集与模型验收尚未完成。
- 部分旧架构与启动文档尚未随迁移更新，启动前需核对源码和服务配置。
