# 用户手册

## 一、学生端

入口：`http://<host>/`

### 登录 / 注册
- **账号**：8 位学号（数字）；**密码**：至少 8 位，必须同时包含字母和数字
- **注册**：学号 + 密码 + 邮箱（邮箱用于找回密码）
- **找回密码**：输入注册邮箱 → 收到重置邮件（含 1 小时有效链接）→ 点链接设新密码 → 重新登录

### 主界面（三栏）
```
┌──────────┬──────────────────────┬──────────────┐
│ 题库来源  │      聊天面板         │  个人中心     │
│ （左侧）  │    AI 问答 + 引用     │ （右侧）      │
└──────────┴──────────────────────┴──────────────┘
```

### 左侧：题库来源
- 文件树：展开目录勾选文件（可多选）——勾选后 AI 只基于这些文件回答
- 上传文件（拖拽或点击）：支持 pdf/docx/ppt/xlsx/txt/md/图片，≤100MB
- 全选/清空按钮；解析状态圆点（绿=完成，转圈=解析中，红=失败）

### 中间：聊天面板
- 输入问题回车发送；AI 回答中：
  - **思考过程**：顶部灰色折叠块（流式实时滚动，完成后折叠为"已思考 N 字"）
  - **正文**：流式轻量渲染（粗体即时），完成后完整 Markdown + 公式（KaTeX）
  - **公式**：支持 `$...$`、`\(...\)` 两种格式
  - **引用来源**：回答下方列出 AI 实际引用的页（去重，最多 8 条），**点击跳到文件对应页**（浮动预览窗口）
  - 流式期间可点停止；完成时浏览器推送通知（需授权）
- 截断提示：回复过长被截断时黄色提示，可去模型选择增大 Max Tokens

### 右侧：个人中心（5 个标签）
| 标签 | 功能 |
|---|---|
| 通用设置 | 主题：浅色 / 深色 / 跟随系统（右上角按钮三态切换） |
| 账号管理 | 改密码（旧+新）、绑定邮箱、登出 |
| 数据管理 | 查看聊天统计、删除全部聊天记录、删除账号（二次确认） |
| 服务协议 | 占位（待定） |
| 模型选择 | **AI 供应商切换**：56 个预设（DeepSeek/SiliconFlow/Kimi/GLM/OpenRouter/Gemini 等）+ 自定义；API Key 输入、模型选择、Base URL、测试连接、高级设置（Temperature/Max Tokens） |

### 模型选择要点
- **思考型模型**（deepseek-v4-flash/glm-4.7 等）：推荐 Max Tokens **16384**（一键应用按钮）
- **多模态模型**（gemini/gpt-4o/qwen-vl 等）：标注"✓ 多模态：图片/PDF 直接给 AI 看图，不走 OCR"
- 保存后立即生效（localStorage + cookie 双写，清浏览器缓存不丢）

### 文件预览窗口
- 点引用或文件树中的文件打开浮动预览
- **PDF**：矢量渲染，缩放清晰（工具栏放大/缩小/旋转/翻页/下载）
- **Word**：docx-preview 高保真排版
- **PPT/Excel/图片**：各自渲染器
- 窗口可拖拽、右下角调大小

## 二、Admin 端

入口：`http://<host>/admin`（未登录跳转登录页）

### 登录
- 初始账号 `admin`，密码为部署时 `ADMIN_SEED_PASSWORD` 设定
- 首次登录后**建议立即改密码**（账号管理 → 改密码）

### 侧边栏
```
📊 概览       仪表盘：文件/聊天/存储统计
🖥️ 监控       服务状态 + 失败统计 + 最近事件（15s 刷新）
👥 用户       学生列表：搜索/禁用/删除/CSV 导出
💬 对话       聊天记录：分页/搜索/批量删除
📁 文件       题库文件：上传/查看/删除/解析状态
📋 日志       审计日志（登录/上传/删除/配置变更）
⚙️ 设置       系统配置（SMTP/告警/站点）
```

### 各页操作
- **概览**：文件完成/失败/解析中统计卡、聊天量、存储占用
- **监控**：6 服务绿/红状态 + 延迟；聊天/解析/登录失败计数；最近事件
- **用户**：按学号/邮箱搜索；禁用（该生无法登录）；删除；导出 CSV
- **对话**：按会话搜索；勾选批量删除；导出
- **文件**：上传（类型白名单+文件名净化）；删除（物理文件+记录）；查看解析状态
- **日志**：审计操作时间线（谁/何时/做了什么/来源 IP）
- **设置**：邮件告警 SMTP、学生邮件 SMTP（独立）、告警开关/收件人、站点 base URL

### 邮件告警配置（首次使用）
1. Admin → 设置 → 填 `smtp_host/port/user/pass`（授权码非登录密码）+ `alarm_emails`
2. 开关 `alarm_enabled` 设 true
3. 保存后停一个服务验证：60 秒内应收到 `【AI题库告警】服务下线`
4. 学生找回密码邮件走 `student_smtp_*`（独立配置，未配则复用告警 SMTP）

### 权限说明（当前）
所有 admin 角色（SUPER_ADMIN/ADMIN/EDITOR/VIEWER）当前权限相同；角色字段已存在，细分权限待后续实现。

## 三、常见问题

| 问题 | 解决 |
|---|---|
| AI 说"题库未覆盖"但文件里明明有 | 确认勾选了对应文件；或该文件解析失败（看左侧红点） |
| 回答引用页不对 | 引用 = AI 实际标注的页（按回答文本提取），AI 可能标错——可点开文件核对 |
| 上传后看不到文件 | 解析中（转圈）需等；失败看红点，重试上传 |
| 浏览器通知没弹 | 首次发消息时浏览器会询问授权，拒绝后需在浏览器设置里手动开 |
| 重置邮件没收到 | 检查垃圾箱；确认 admin 已配 `student_smtp_*`（未配则邮件走告警 SMTP） |
